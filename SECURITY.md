# Security Policy

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues, pull requests, or other public channels.

If you believe you have found a security vulnerability in this repository or one of its artifacts, report it privately to [Red Hat Product Security](https://access.redhat.com/security/team/contact) at **secalert@redhat.com**.

When possible, include:

- The affected scenario, script, manifest, or container image
- The commit, version, or image tag involved
- Steps to reproduce the issue
- The potential security impact
- Relevant logs or a minimal proof of concept
- Whether the issue is already publicly known

Please do not include credentials, cluster access tokens, private keys, or other sensitive data in an issue or pull request. Use the Red Hat Product Security process for sensitive material and request secure communication if needed.

## Scope

This repository contains OpenShift troubleshooting scenarios, evaluation fixtures, setup and cleanup scripts, and demo applications. It is not a production service or a supported production release artifact. Reports are still welcome for vulnerabilities that could affect users running the repository's scenarios, scripts, or published demo images.

For general questions, configuration problems, or non-security bugs, please use the repository's normal issue and pull request process.
